📱 Installer sur Android
  1. Touchez le bouton Android de l'application voulue : le fichier se télécharge.
  2. Ouvrez le fichier téléchargé. Si le téléphone le demande, autorisez l'installation depuis le navigateur.
  3. Touchez Installer. À la première photo, autorisez la caméra.
💻 Installer sur un PC Windows
  1. Cliquez sur le bouton Windows de l'application voulue, puis ouvrez le fichier téléchargé.
  2. Si Windows affiche « Windows a protégé votre PC » : Informations complémentaires puis Exécuter quand même.
  3. Cochez « Créer une icône sur le Bureau », puis lancez l'application.
